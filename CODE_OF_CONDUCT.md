# Code of Conduct

We want this to be a welcoming project for everyone, whatever their experience, background or identity.

**Expected:**
- be kind and assume good intent;
- give feedback on the work, not the person;
- credit others' ideas;
- help newcomers.

**Not accepted:**
- harassment, insults or discriminatory language;
- personal attacks;
- publishing others' private information;
- sustained disruption.

**Reporting:** contact a maintainer privately (@Mgabr90 or @Ahmed0623 on GitHub). Reports are handled confidentially. Maintainers may edit or remove contributions, or block participants, who break this code.

This code is inspired by, and should be read in the spirit of, the [Contributor Covenant](https://www.contributor-covenant.org/).
